PHP Assignment 3 - Student Registration Form

Files:
- index.php: Student registration form and server-side validation.
- display.php: Displays submitted student information in a separate table.
- style.css: Styling and responsive design.
- uploads/: Stores uploaded student images.

How to run:
1. Install XAMPP or another PHP server.
2. Copy the PHP_Assignment_3 folder into the server's web directory (for XAMPP, htdocs).
3. Start Apache.
4. Open http://localhost/PHP_Assignment_3/index.php in your browser.
5. Complete all fields and upload a JPG, PNG, or GIF image (maximum 2 MB).

Notes:
- Bootstrap is loaded from its CDN, so an internet connection is needed for Bootstrap styling.
- Make sure the uploads folder is writable by PHP.
- The project uses PHP sessions to pass the submitted information to display.php.
